# RTL8367 Switch 设计说明

本文记录 v0.1 的设计依据与取舍。

## 1. 关键器件

| 用途 | 型号 | 立创料号 |
|---|---|---|
| 交换芯片 | RTL8367RB-VB-CG（E-Pad LQFP-128） | C2761412 |

| 3.3 V → 1.1 V | TPS62130ARGTR + 2.2 µH | C337502 |
| 复位监控 | TPS3808G30DBVR（门限 2.79 V） | C189211 |
| 网络变压器 × 5 | Pulse H5007NL | C6384935 |

没有选 RTL8367S，是因为 RB 的热阻低得多：θJA 16.5 °C/W，S 是 45 °C/W。

## 2. 供电

```
12 V ─ F101 ─ D101（防反接）─ VIN ─┬─ D102 TVS
                                   └─ TPS54331 ─ +3V3 ─┬─ TPS62130A ─ +1V1（核心）─┬─ FB202 ─ +1V1A
                                                       │                           └─ FB203 ─ +1V1P
                                                       ├─ FB201 ─ +3V3A
                                                       └─ TPS3808 复位监控、LED、EEPROM
```

- 复位：TPS3808 监控 +3V3，1.1 V 降压的 PG、手动复位按键和监控器的 MR 接在同一个网络上，任何一个拉低都会让芯片复位。
- 3.3 V 降压放在正面右后角，按电流方向从右到左排列：插座 → 保险丝 → 防反接二极管 → 输入电容 → TPS54331 → 续流二极管 → 电感 → 输出电容。
  - 铺铜：VIN、SW、输出各一块。SW 铜皮只包芯片 SW 脚、续流二极管和电感。
  - 自举电容跨在芯片下方，两端分别对着 BOOT 脚和 SW 脚。
  - 输入电容、续流二极管、输出电容的地端都就近打一排过孔到第 2 层。
- 1.1 V 降压（TPS62130A，2.5 MHz）放在背面，紧挨芯片。
  - SW2、+1V1、+3V3 各有一小块铺铜，外加一块局部地铺铜，输入环路 PVIN–C112–PGND 在背面就地闭合。
  - 输出经电感下方的过孔进入第 3 层的 +1V1 区。
  - 反馈分压器放在正面板边，VOS 和分压器上端在输出过孔处同点采样。

## 3. 叠层与规则

| 层 | 用途 | 厚度 |
|---|---|---|
| F.Cu | 信号：MDI 全部在这层；大件 | 1 oz |
| 预浸料 | 3313 × 2 | 0.107 + 0.0994 mm |
| In1.Cu | 整层地（芯片侧） | 0.5 oz |
| 芯板 | | 1.065 mm |
| In2.Cu | 电源分区 | 0.5 oz |
| 预浸料 | 3313 × 2 | 0.0994 + 0.107 mm |
| B.Cu | 慢信号、去耦电容、1.1 V 降压 | 1 oz |

- 叠层是嘉立创 JLC04161H-3313A，总厚 1.58 mm。
- MDI 按 100 Ω 差分设计：线宽 0.226 mm、线距 0.203 mm，由嘉立创阻抗计算器按这个叠层算出。
- 最小线宽 0.2 mm；芯片引脚间距只有 0.15 mm，所以电源网络的间距设为 0.15 mm。
- 过孔 0.45 / 0.3 mm；缝合孔 0.6 / 0.3 mm。

## 4. 布局

- 5 个网口沿前边排列，间距 19.5 mm，板宽由此决定。
- 每个网口正后方是它的变压器，变压器后面是这个口的两颗 LED；芯片侧中心抽头的电容在变压器后面的背面，线缆侧的 Bob Smith 电阻和电容在变压器与网口之间的背面。
- 交换芯片居中，在变压器后面，晶体在芯片左侧，电源在后边。
- 双面贴片：大件在正面；去耦电容、上下拉电阻、LED 限流电阻、中心抽头电容、终端电阻和测试点放在背面。

## 5. MDI

- **芯片到变压器**：在原理图里重新分配了每个口变压器 4 个通道和芯片 4 对差分线的对应关系，使 20 对线从芯片引脚到变压器全部在顶层直走，不打孔、不交叉，下面是完整的第 2 层地。
- **线对顺序和极性**：变压器之后、网口下方那一段做换序。
  - 为了不交叉，每对线在网口侧的正负标号做了对调。
  - RTL8367RB 在 1000BASE-T 和 10BASE-T 下会自动纠正线对极性，100BASE-TX 对极性不敏感（数据手册 Pre-0.92，§8.10）。
- **线缆侧**：
  - 四个线对分走四层（A 顶层、B 第 2 层、C 第 3 层、D 底层），直接接到网口的通孔脚。
  - 这一段的地和电源平面全部挖空，与芯片侧之间留隔离带。
- **中心抽头**：
  - 芯片侧每个抽头 0.1 µF 到地，并预留一个 0 Ω 到 +3V3A 的位置（默认不贴）。
  - 线缆侧每个抽头 75 Ω 汇到一点，经 1 nF / 2 kV 接 CHASSIS（Bob Smith 终端）。
- **ESD**：每对线旁预留了 TPD4E02B04（直通式，默认不贴），走线直接穿过它的焊盘。

## 6. 电源完整性

- 第 2 层在芯片侧是整层地。第 3 层在芯片下方分出几个区：
  - +1V1 核心区，并伸出一条 2 mm 宽的“手指”到背面的 1.1 V 降压；
  - +1V1A 环；
  - +3V3A 环（另有一条支路给中心抽头的预留位）；
  - 其余是 +3V3 主电源。
- 芯片的每个电源脚旁都打一个过孔，直通背面的 0402 去耦电容，电容的地端再就近打孔。
- 散热焊盘下的 16 个过孔同时是芯片的主要地回路，背面这块区域不放器件。
- 外层在平面范围内铺地，离其他铜 0.4 mm，并打缝合过孔连到第 2 层。

## 7. 时钟与控制

- 25 MHz 晶体离 XTAL 脚很近，两颗负载电容直接贴在晶体焊盘旁，晶体下方的焊盘之间有地连接。
- 扩展口（RGMII）引脚的下拉电阻排成一行，放在芯片后方。
- 10 路 LED 信号在背面汇成一组总线，到各口再分出去。
- J251 引出 SMI 的时钟和数据线，加上 3.3 V 和地，用来读写寄存器。
- EEPROM（AT24C256C）的位置已预留，默认不贴。
