# 生产文件

由 `kicad-cli` 从 `rtl8367-switch.kicad_pcb` 导出，坐标原点 = 板左上角（钻孔/贴片原点）。

## 下单参数

| 项 | 值 |
|---|---|
| 层数 | 4 层 |
| 板厚 | 1.6 mm（叠层实际 1.58 mm），FR4 |
| 叠层 | 嘉立创 **JLC04161H-3313A**：F.Cu / 3313 × 2 / In1（地）/ 1.065 mm 芯板 / In2（电源分区）/ 3313 × 2 / B.Cu。**内层顺序不要调换** |
| 铜厚 | 外层 1 oz，内层 0.5 oz |
| 阻抗 | MDI 差分 100 Ω：0.226 / 0.203 mm（按上面的叠层计算） |
| 尺寸 | 100 × 72 mm |
| 表面处理 | 无铅喷锡 |
| 阻焊 / 丝印 | 绿油 / 白字 |
| 过孔 | 盖油 |
| 最小线宽 / 间距 | 0.2 / 0.15 mm |
| 过孔（外径/孔径） | 0.45/0.3（296 个）、0.6/0.3（69 个） |
| 焊盘孔 | PTH 0.2 mm（U102 封装自带的散热孔，4 个）、0.3 / 0.9 / 1.0 / 1.6 / 1.8 mm；NPTH 3.2 mm（4 个安装孔）、3.25 mm（网口定位柱） |
| 贴片 | 双面：正面 56 个，背面 129 个 |

0.2 mm 的散热孔和 0.15 mm 的间距，下单前请对照所选板厂的工艺能力确认。

## 文件

- `rtl8367-switch-gerber.zip`：上传用，含 11 层 Gerber（X2）、PTH/NPTH 分开的 Excellon 钻孔、`.gbrjob`。
- `gerber/`：同上的散文件，另有钻孔分布图 PDF。
- `rtl8367-switch-bom.csv`：按 值 + 耐压 + 封装 合并；默认不贴的器件（ESD 预留位、EEPROM、中心抽头的 0 Ω 选项等）、安装孔和测试点不在表里。
- `rtl8367-switch-pos.csv`：两面的贴片坐标（mm，原点在板左上角）。用嘉立创贴片时需要按其模板改列名并补立创料号，料号见 [docs/design.md](../docs/design.md)。
- `rtl8367-switch-assembly.pdf`：装配图。第 1 页正面，第 2 页背面（镜像）。丝印上放不下而隐藏的小阻容位号都在这里。
- `rtl8367-switch-drc.rpt`：DRC 报告，0 错误、0 未连接。唯一一条警告是 J101 与库里的封装不一致：DC 插座伸出板边，超出板边的丝印线被有意删掉了。
